# Política de Segurança 🔒

A segurança do projeto **Game Play** e dos seus usuários é levada a sério. Se você acredita ter encontrado uma vulnerabilidade de segurança, agradecemos sua ajuda em nos comunicar de forma responsável.

---

## Versões com Suporte

| Versão | Suportada          |
| :---   | :---:              |
| 1.0.x  | :white_check_mark: |
| < 1.0  | :x:                |

---

## Como Reportar uma Vulnerabilidade

**Por favor, NÃO abra uma Issue pública no GitHub para relatar problemas de segurança.**

Em vez disso, siga as instruções abaixo:

1. Envie um e-mail com os detalhes da vulnerabilidade para:
   - **E-mail:** `luanhsouzaf@gmail.com`
2. No corpo da mensagem, inclua:
   - Tipo de problema (ex.: vazamento de credenciais, injeção, etc.)
   - Passos detalhados para reproduzir o problema
   - Um exemplo de código ou prova de conceito (PoC), se aplicável
   - O impacto potencial da vulnerabilidade
3. Você receberá uma confirmação de recebimento dentro de **48 horas**.
4. Faremos o possível para investigar, validar e fornecer uma correção ou plano de mitigação o mais rápido possível.

---

## Divulgação Responsável

Pedimos que você nos dê um prazo razoável para corrigir a vulnerabilidade antes de qualquer divulgação pública, visando proteger todos os usuários e dados da aplicação.
